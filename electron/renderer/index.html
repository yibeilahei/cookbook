    Settings ()

    Detected from your system language by default. Picks recommended fonts below and, in .xtch mode, whether filenames/chapter names get romanized for readability.

    Makes .xtch filenames and chapter names ASCII-safe using proper Japanese/Chinese/Korean romanization (e.g. Hepburn romaji). On by default for those languages; not applicable otherwise (other scripts are already made ASCII-safe automatically).

    Stores each .xtch page as raw-DEFLATE when that shrinks it. Off by default: currently the only firmware that supports page compression is lazahata.

    Default PDF font size Calibre uses when converting ebooks. Applies across all devices in this mode.
